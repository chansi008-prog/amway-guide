# 소비자 관리

암웨이 사업자용 소비자 관리 + 제품 가이드 웹앱(PWA)입니다.
iPhone은 Safari에서, Android는 Chrome에서 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있어요.

- 홈: 오늘 / 이번 주 할 일 (필터 교체, 놓친 고객, SOP 결제, 소개 후속, 생일·기념일, SOP 해지, 영양제 재구매)
- 소비자 카드: 관심 항목 Top 5, 추천 제품, SOP, 필터 기기, 구매·소개 기록
- 필터 교체 예정, SOP 관리, 제품별 구매자 조회, 관심 항목별 소비자
- 제품 가이드: 고민별 추천, 가격, 영양제 섭취 방법과 1통 섭취 기간

소비자 정보는 휴대폰 안(브라우저 저장소)에만 저장됩니다. 설정 > 내보내기로 백업하세요.
계산 규칙 자동 테스트: `tests.html`을 열면 결과가 나옵니다.
카탈로그 「The Choice」 Autumn 2026 Vol.75 기준. 비공식 개인용 도구입니다.

## 파일
- `index.html` 화면 틀과 디자인
- `js/app.js` 화면과 입력 창
- `js/logic.js` 계산 규칙 (교체 예정일, 할 일, 추천)
- `js/store.js` 저장소 (나중에 서버로 옮길 때 이 파일만 바꾸면 됨)
- `js/catalog.js` 제품 데이터
- `js/sample.js` 둘러보기용 예시 데이터
